BUILT IN THE OPEN

Local routes. Clear information.

CobyTransit is an independent, open-source project by Sohaib Khan. It is not an official county or SUNY service.

Real data. Clear limits.

Schedule dates and freshness appear in the status banner above. Service notices can override published calendars; call before travel.

There is no connected GPS, live arrival prediction, occupancy, reservation system, or verified live alerts feed. Vehicle demo mode is an animation only.

Your trip stays yours.

No app accounts, analytics, payment collection, or geolocation requests. Saved stop IDs and opt-in offline schedules stay in this browser and can be cleared below. Offline data cannot include new cancellations. The hosting provider may retain standard request logs.

All application scripts and data are served by this site. Street tiles are off by default; enabling them contacts OpenStreetMap, which receives your IP address and the map area viewed. External links contact their destination when opened.

Security by design

The rider interface has no app accounts, payments, location access, or user uploads. Security headers are enforced by the server. A protected maintenance endpoint accepts validated transit snapshots; it cannot fetch arbitrary addresses. User input is rendered as text, never HTML.

Security, calendar, return-trip and offline-cache regression tests are included in the source. Production headers are checked with authenticated service access. This prototype has not had an independent penetration test.
